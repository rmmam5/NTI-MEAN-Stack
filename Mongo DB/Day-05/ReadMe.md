# Day 05 — MongoDB Data Modeling, Aggregation & Backup

## 📌 Overview

This day focuses on MongoDB data modeling, aggregation pipelines, `$lookup`, `$group`, `$match`, `$unwind`, and database backup, restore, import, and export operations.

## 📚 Topics Covered

- MongoDB Data Modeling
  - Embedded Data Model
  - Referencing / Normalized Data Model
- Relationships Between Collections
- MongoDB Aggregation
  - `$match`
  - `$group`
  - `$lookup`
  - `$unwind`
  - `$sum`
  - `$avg`
  - `$max`
- Aggregation with Multiple Stages
- Joining Collections using `$lookup`
- Filtering Aggregation Results
- Counting and Calculating Values
- MongoDB Backup & Restore
  - `mongodump`
  - `mongorestore`
- MongoDB Import & Export
  - `mongoimport`
  - `mongoexport`
- MongoDB Atlas

## 🎯 Learning Objectives

- Understand embedded and normalized data models in MongoDB.
- Model relationships between collections.
- Use aggregation pipelines to analyze and transform data.
- Group documents and perform calculations.
- Join related collections using `$lookup`.
- Filter and process array data using `$unwind`.
- Perform database backup and restore operations.
- Import and export MongoDB data.
