# Day 04 — MongoDB CRUD, Queries & Indexing

## 📌 Overview

This day covers MongoDB fundamentals, CRUD operations, queries, operators, data modeling, aggregation, and indexing.

## 📚 Topics Covered

- MongoDB Fundamentals
- MongoDB Server, Mongo Shell & Compass
- Database & Collection Management
- CRUD Operations
  - Create
  - Read
  - Update
  - Delete
- `find()` & `findOne()`
- Projection
- Filtering & Pagination
  - `limit()`
  - `skip()`
- Sorting
- Update Operators
  - `$set`
  - `$inc`
  - `$unset`
  - `$push`
  - `$pull`
- Query Operators
  - Comparison Operators
  - Logical Operators
  - Element Operators
  - Evaluation Operators
- Indexing
  - Single Field Index
  - Compound Index
  - Multikey Index
- Data Modeling
  - Embedded Data Model
  - Normalized Data Model
- Aggregation Pipelines
- Backup & Restore
- Import & Export
- MongoDB Atlas

## 🎯 Learning Objectives

- Understand MongoDB databases, collections, and documents.
- Perform CRUD operations using MongoDB.
- Query and filter documents efficiently.
- Use projection, sorting, pagination, and different operators.
- Create and manage indexes.
- Understand embedded and normalized data models.
- Understand MongoDB aggregation pipelines.
- Work with MongoDB backup, restore, import, and export tools.
