## Task

Created a **Get Data** button that:

- Fetches products from **DummyJSON API** when clicked.
- Converts the response to JSON.
- Loops through products using `forEach()`.
- Creates product cards dynamically using the DOM.
- Displays:
  - Product Image
  - Product Title
  - Product Description
  - Product Price
- Hides the button after successfully fetching the data.
- Handles errors using `.catch()`.

## API Used

**DummyJSON Products API**

https://dummyjson.com/products
